# Zakres zmian

Zmiana w kodzie może obejmować **tylko** to, o co prosi użytkownik.

## Niedopuszczalne

Dobrowolne dodatki „przy okazji”, nawet gdy wydają się poprawą lub są powiązane tematycznie:

- zmiana znaczników, ikon, kształtów (np. pinezka zamiast trójkąta gracza)
- podmiana kolorów, etykiet, układu UI
- refaktory i „porządki” poza własnym bałaganem z tej samej zmiany
- cokolwiek innego, czego użytkownik **nie wskazał**

## Dopuszczalne

- dokładnie wskazany cel (np. naprawa spawnu, lista miejsc)
- sprzątanie wyłącznie tego, co ta zmiana sama zostawiła (zbędne importy, martwy kod z tego diffu)

Jeśli coś wygląda źle, ale nie zostało nazwane w prośbie — najpierw zapytać, nie zmieniać.
